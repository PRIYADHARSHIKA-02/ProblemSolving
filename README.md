# Problem Solving

Practice solutions for coding problems, mostly from LeetCode, along with a few Java pattern programs.

## Structure

- `src/LeetCode/java` - Java solutions
- `src/LeetCode/java/Array/Easy` - easy array problems
- `src/LeetCode/java/Array/Medium` - medium array problems
- `src/LeetCode/java/BinarySearch` - binary search problems
- `src/LeetCode/python` - Python solutions
- `src/Patterns` - basic Java pattern programs
- `bin` - compiled/output files generated by the IDE

## Notes

Most files are standalone solutions. Open the file for the problem you want to check and run it with Java or Python from your editor/terminal.

For Java files, compile from `src` if needed:

```bash
javac LeetCode/java/Array/Easy/TwoSum.java
```

For Python files:

```bash
python "LeetCode/python/8. MaxSubarray.py"
```

This repo is mainly for keeping track of practice and revisions.
